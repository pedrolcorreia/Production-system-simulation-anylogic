# Project notes

Use this file to document your own contribution to the team project before publishing.

Suggested prompts:

- Which blocks / processes did you personally implement in AnyLogic?
- Which verification checks did you perform?
- Which data distributions did you fit or validate?
- Which experiments did you configure or analyze?
- Which conclusions/recommendations did you personally contribute?

Avoid presenting team work as individual work. Specific personal contributions make the repository much more credible in interviews.
